Lunar Farm — performance profile

Times the three things that happen every frame — the simulation tick, the agent update and the render — at an empty farm, a mid-game farm and a farm built out to the edges of the plot. Then counts the canvas operations each render issues, so a slow frame can be traced to the thing issuing the work rather than guessed at.

A frame has 16.7 ms at 60fps. These figures are CPU-side: canvas calls are queued and flushed by the GPU, so the true cost of a draw is at least this and never less. Measured on whatever machine opens this page, so compare runs on one machine rather than across two.
